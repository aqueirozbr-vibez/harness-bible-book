## Beats analysis
- Vaswani 2017: mechanism complete; stops at training; no cache, no cost.
- Dao 2022–24: kernels and throughput; stops at "how fast"; does not tell an operator what context length their hardware can serve.
- Ainslie 2023: quality/speed on T5; stops before decoder-only serving arithmetic and agentic quality.
- DeepSeek-V2: MLA mechanism and 93.3% figure; stops at "trained from scratch."
- Alammar, Karpathy, Weng, Huyen: intuition, code, survey; none carries one model from formula to bytes to a serving decision.

## Worked-number inputs
KV bytes/token = layers × KV heads × head_dim × 2 (K,V) × bytes. Llama 3 (source 5): 8B 32×8×128×2×2 = 131,072 B = 128 KB; 70B 80×8×128×2×2 = 327,680 B = 320 KB; 405B 126×8×128×2×2 = 516,096 B = 504 KB. Same models without GQA (KV heads = query heads): 8B 512 KB; 70B 2,560 KB; 405B 8,064 KB. DeepSeek-V2 MLA (source 12): per layer per token 576 scalars vs 16,384 → 3.5% (paper reports 93.3% total reduction vs DeepSeek 67B, which has a different layer count and head count). Attention score FLOPs per layer ≈ 2·n²·d_model (QKᵀ) + 2·n²·d_model (AV) for full-sequence prefill; MLP FLOPs per layer ≈ 16·n·d_model² for a 4× MLP (Llama uses SwiGLU with 3 matrices at 3.5× — use the paper's dimensions where exact).

## Lab candidates
No dataset needed: synthetic random Q/K/V with fixed seed. Hardware: CPU only (NumPy), n from 256 to 8,192, d=128; runtime < 2 min. Reproduces: the quadratic exponent of attention time vs n, and the Llama 3 KV-cache bytes per token.
