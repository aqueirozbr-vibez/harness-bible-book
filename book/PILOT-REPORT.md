## Decisions taken (apply to all remaining chapters)
1. **Word budgets count prose plus tables; code and equations excluded.** Pilot chapters landed at 55–75% of the original budgets even so. Revised floors: foundations 5,000; harness 5,000; industrial 4,500. Ceilings unchanged. Padding to a budget is the failure the standard prevents.
2. **Every derived number comes from a committed script** (`labs/chNN/derive.py`). Chapter 04's four hand-arithmetic errors set this rule; chapter 37 was written numbers-first and reproduced without correction.
3. **Labs run the chapter's own code**, extracted verbatim from its Python blocks, so text and executable cannot drift (chapter 28 pattern).
4. **Linter checks citations per paragraph**, strips math, treats `$` followed by a digit as currency, and accepts tiers: primary, vendor, analyst, illustrative, derived, open, practitioner, scenario.
5. **Unverifiable figures are dropped, not hedged.** Chapter 28 lost three claims this way (CaMeL-Strict/ADI numbers, Prompt Guard latency, a CISA document); the chapter is stronger for it.
6. **VERIFY and REDTEAM by the drafting instance are pre-reviews only.** The gate requires an independent pass; nothing in this pilot has met the gate yet.
