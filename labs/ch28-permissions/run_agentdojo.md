# Lab 28b — Attack success rate with and without the gate (API-gated)

Protocol: install `agentdojo` (MIT); select the workspace suite; run a minimal tool-calling agent twice — tools called directly, and tools wrapped in `pdp.guard` with a policy encoding the suite's intended permissions (reads allowed; sends and writes escalate). Report targeted ASR and utility under attack for both, with Wilson confidence intervals over the case count. Requires `ANTHROPIC_API_KEY` or `OPENAI_API_KEY`; the runner prints an estimated token cost before starting and refuses without `--confirm`. Expected outcome: ASR falls to the fraction of injection tasks whose target action is a read; utility under attack falls by the fraction of benign tasks that need a write without an approval path. Record model version, date, and policy bundle hash.
